What's New in CUDA 13.4

Start with these CUDA 13.4 highlights, then open the release notes for the complete list of changes.

  • Windows on Arm - The CUDA Toolkit is now supported on Windows on Arm platform for RTX Spark devices.
  • NVIDIA Rubin preview - Adds preview support for the NVIDIA Rubin architecture.
  • MPS V3 - Introduces CUDA MPS V3, simplifying the automation and management of shared GPU resources.

Read the CUDA Toolkit Release Notes for the complete CUDA 13.4 feature list, resolved issues, known issues, deprecations, and compatibility notes.
